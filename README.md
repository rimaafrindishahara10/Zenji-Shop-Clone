
# 🚀 ZENJI Clone — Frontend Assessment

A modern frontend clone of **zenji.shop** built with **Next.js 16 (App Router)**.

---

## 📌 Project Overview

This project is a responsive e-commerce landing page developed as a frontend assessment. It focuses on clean UI, reusable components, smooth scrolling, and modern animations.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| Next.js 16 (App Router) | React framework & routing |
| React | UI development |
| Tailwind CSS | Styling |
| Framer Motion | Animations |
| Lenis | Smooth scrolling |

---

## ✨ Features

- Responsive design
- Modern UI with Tailwind CSS
- Smooth scrolling using Lenis
- Interactive animations with Framer Motion
- Reusable component architecture

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
# Clone repository
git clone <https://github.com/rimaafrindishahara10/Zenji-Shop-Clone>

# Enter project
cd zenji-shop-clone

# Install dependencies
npm install

# Start development server
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
